# Агент по сбору новостей от МПС

Python-агент раз в сутки собирает русско- и англоязычные новости о Visa и
Mastercard из Google News RSS, исключает уже отправленные материалы, делает
короткие саммари через Groq по заголовку и RSS-сниппету и отправляет по SMTP
письмо с HTML-таблицей: заголовок, ссылка, краткое содержание.

## Возможности

- четыре бесплатных RSS-запроса: Visa и Mastercard на русском и английском;
- фильтрация по возрасту и удаление дублей;
- поверхностная аналитика через Groq (batch-запрос);
- HTML-таблица и текстовая версии письма;
- локальный dry-run без отправки;
- ежедневный запуск через GitHub Actions без отдельного хостинга.

## Локальный запуск

Требуется Python 3.9 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
cp .env.example .env
```

Для проверки сбора без SMTP установите в `.env`:

```dotenv
DRY_RUN=true
```

При dry-run ключ Groq не обязателен: если его нет или запрос не удался,
в письмо попадёт RSS-сниппет или текст «Краткое содержание недоступно».

Затем запустите:

```bash
payment-news-agent
```

Найденные новости будут напечатаны в терминале. В dry-run они намеренно не
добавляются в историю отправки.

## Настройка SMTP

Заполните `.env` для локального запуска или создайте одноимённые GitHub
Repository Secrets:

- `SMTP_HOST` — SMTP-сервер почтового провайдера;
- `SMTP_PORT` — порт, обычно `587` для STARTTLS;
- `SMTP_USER` — SMTP-логин;
- `SMTP_PASSWORD` — пароль или пароль приложения;
- `SMTP_USE_TLS` — `true` для STARTTLS (порт 587);
- `SMTP_USE_SSL` — `true` для SMTPS (порт 465); не включайте вместе с TLS;
- `SMTP_TIMEOUT` — таймаут соединения в секундах, по умолчанию `60`;
- `MAIL_FROM` — адрес отправителя;
- `MAIL_TO` — один адрес или несколько через запятую.

Для Gmail обычно: `smtp.gmail.com`, порт `587`, `SMTP_USE_TLS=true` и пароль
приложения. Для Yandex/Mail.ru часто нужен порт `465` и `SMTP_USE_SSL=true`.

## Настройка Groq

1. Создайте API-ключ на [console.groq.com](https://console.groq.com).
2. Добавьте в `.env` или GitHub Secrets:

- `GROQ_API_KEY` — ключ API (обязателен при реальной отправке, если саммаризация включена);
- `GROQ_MODEL` — модель, по умолчанию `llama-3.1-8b-instant`;
- `SUMMARIZE_ENABLED` — `true`/`false`, по умолчанию `true`.

Саммари строятся только по заголовку и сниппету RSS, без загрузки полного
текста статьи.

Дополнительные параметры:

- `NEWS_MAX_AGE_HOURS` — максимальный возраст новости, по умолчанию 48 часов;
- `NEWS_LIMIT_PER_BRAND` — максимум новостей каждого бренда, по умолчанию 20;
- `STATE_FILE` — путь к истории отправки, по умолчанию `state/sent.json`;
- `DRY_RUN` — не отправлять письмо, а вывести его текст.

## GitHub Actions

Workflow [`.github/workflows/daily-news.yml`](.github/workflows/daily-news.yml)
запускается ежедневно в 04:00 UTC и вручную через вкладку Actions. Добавьте
SMTP-переменные и `GROQ_API_KEY` в `Settings → Secrets and variables → Actions`.
`GROQ_MODEL` можно задать секретом или оставить пустым — тогда используется
значение по умолчанию из кода/`env` workflow.

История отправленных новостей сохраняется в GitHub Actions cache. Если cache
будет очищен, отдельные новости могут прийти повторно.

## Ограничения

Google News RSS не гарантирует полный охват интернета и может менять выдачу.
Ссылки ведут через редирект Google News на исходный материал. Саммари
поверхностные: модель не читает полный текст статьи. Для строгого списка
изданий, полного текста или гарантированного SLA потребуется отдельный
news/search API.
